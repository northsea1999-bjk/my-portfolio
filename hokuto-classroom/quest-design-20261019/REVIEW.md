# 호쿠토증권 v2.0 · v7.3 검토 기록

이번 변경은 별도 공개 디자인 시안에만 적용한다. 운영 v1.0은 변경하지 않는다. 모든 투자·뉴스 자료는 가상이다.

## 반영 사항

- 로고 도형과 HOKUTO 유지, 아래 작은 표기를 SECURITIES로 변경.
- 공통 헤더에 한국어 / 일본어 원문 제목 전환 버튼 추가. 기사 카드·목록·상세에 공통 적용하고 선택 유지.
- 일본어 4건은 **전환 시연을 위해 새로 쓴 가상 제목**이다. 실제 원문을 확보했다고 표시하지 않으며 ‘일본어 예시’ 표기를 붙인다. 원문 예시가 없는 2건은 기존 제목과 원문 없음 안내를 유지한다.
- 새로운 버튼·안내 문구를 ui-copy.js 한곳에서 관리. 기존 전체 문구 통합은 아직 완료되지 않았다.
- 이전에 확정한 알림홈 ↔ 전체메뉴 기본 이동, 중복 큰 버튼 제거, 주제별 필요한 연결은 유지.

## 운영 v1.0과의 대조

운영 오늘 화면을 브라우저로 직접 확인했다. 운영의 사적인 보유 목록·수익·종목별 판단은 이 공개 문서에 복사하지 않는다.

| 항목 | 비교 결과와 이관 기준 |
|---|---|
| 제목 전환 | v1.0에 있는 기능이 시안에서 빠져 있었음. v7.3에 추가. 운영에서는 기존 원문/번역 필드를 재사용 |
| 뉴스 전체 목록 | 시안의 6건은 예시. 운영의 뉴스룸 전체 목록·실제 건수·최신순·나머지 펼치기를 보존. 특정 건수를 하드코딩하지 않음 |
| 번역 상태 | 한국어 모드에도 번역되지 않은 원문이 존재함. 번역 없음과 번역 완료를 구분하고 원문을 누락하지 않음 |
| 자료 시각 | 운영은 판정·리서치 기준일, 화면 생성 시각, 뉴스 수집 시각을 구분. 시안의 고정 날짜를 실제 날짜처럼 사용하지 않음. 거래일·평가일·수집일·다음 거래일을 분리 |
| 내 주식·결정실·신규매수 | 화면 입구는 유지했지만 시안 데이터는 가상. 보유 점검·후보 판정·진입 조건을 별도로 유지하고 운영 건수나 판단을 화면에서 재계산하지 않음 |
| 하루 변화 | 전체메뉴 결과·기록 구역에 유지. 운영의 전일 대비 변화 항목과 기준 시각을 대응시킬 것 |
| 테마·후보·BNF | 이름이 비슷해도 역할과 계산은 다를 수 있음. 실제 운영 각 방의 입력·결과 대응표를 확인해야 함. 전체 업무 동등성 검증 완료는 아님 |
| 성과기록·선정성적·매매 전략/규칙 | 현재는 안내 화면이며 상세 데이터 미연결. 운영 대체 완료로 볼 수 없음 |
| 차트 | 6개월 구간 표시 유지. 현 시안의 가격 샘플은 20거래일이고 앞 구간은 빈 날짜만 존재함. 실제 6개월 가격·거래량 확보 없이 채우지 않음 |
| 번역 문구 통합 | 신규 문구는 통합. 기존 전체 화면 문구의 통합은 미완료. COPY-REVIEW.md 참조 |

## 확인

- numeric-verification-v73.json: 7개 가상 종목, 후보/결정/신규매수 대상, 점수 비교, 기존 기사 데이터, OHLCV fixture가 이전 시안과 동일.
- 일본어 표시 금액·전망 수치 보존 및 원문 없음 fallback 확인.
- 공개 시안에서 PC, 휴대폰 360/390/430px 표시 확인. 가로 넘침 없음.
- 한국어 → 일본어 예시 → 한국어 복원, 원문 없음 2건 표시, 기사 상세 제목, 전체메뉴 왕복 후 선택 유지 확인.
- 큰 글자 모드에서도 제목 버튼과 메뉴 이동 확인. 운영 원문 버튼은 비교 후 원래 한국어 모드로 복원.
- 360px 검색창 폭 보완을 반영하고 최종 화면을 다시 확인. 확인 이미지: quest-v73-final-home.jpg.
