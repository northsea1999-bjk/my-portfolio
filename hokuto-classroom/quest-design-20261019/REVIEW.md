# 호쿠토증권 디자인 v2.0 — quest v7 연결 정리

기준: 사용자가 지정한 quest v6. clear-design의 6카드 재구성안을 적용하지 않는다.
2026-10-19 사용자 지시: 알림홈은 유지하되 첨부 이미지의 큰 버튼 3개와 운영 화면 연결을 제거한다. 전체메뉴의 큰 카드 3개, 알림홈 연결, 기존 호쿠토 입구를 제거한다. 나머지 연결은 주제별로 선별한다.

## 수정한 범위

- 알림홈: 기존 색감·픽셀 그래픽·3건 브리핑·전체 뉴스 제목·종목 목록·차트 배치 유지. 위쪽 큰 구역 버튼 3개 제거. 운영 뉴스 연결 제거. 기사 제목은 현재 화면에서 상세 창으로 연다.
- 전체메뉴: 기존 6단계 안내도와 주제별 구분 유지. 상단 큰 카드 3개를 작은 ‘오늘 뉴스 / 내 주식 / 하루 변화’ 메뉴 한 줄로 전환. 기능을 없애지 않는다. 알림홈 링크와 로고의 홈 링크, 기존 오늘·사무실 입구, 예전 시안 비교 링크 제거.
- 주제 화면: 상단에 현재 주제와 전체메뉴 입구만 표시. 각 방에 반복되던 6단계 이동 막대·다음 단계 이동·운영 화면 연결 제거.
- 자료가 있는 메뉴 14개와 안내만 있는 메뉴 3개를 포함하여 비운영 입구 17개 유지. 주제 이름과 기존 분류는 임의로 합치지 않는다.

## 필요한 연결을 남기는 기준

| 출발점 | 남긴 동작 | 줄인 동작 |
|---|---|---|
| 알림홈 브리핑 | 경고·판정·후속 뉴스의 해당 내용 | 위쪽 대형 구역 바로가기 3개, 운영 뉴스 연결 |
| 기사 제목 / 내 주식의 관련 뉴스 | 해당 기사 상세 창, 입력 자료 펼치기 | 기사 창에서 다른 테마나 종목 화면으로 이동 |
| 종목 근거·지난 기록 | 같은 화면의 상세 창, 같은 종목 날짜 선택 | 알림홈으로 이동하여 분석 다시 찾기 |
| 회의실 | 테마 선택·수치 비교 | 작전실로 가라는 하단 다음 버튼 |
| 작전실 | 실제 후보가 있는 테마의 해당 후보 확인 | 후보 없는 테마의 빈 이동 |
| 전략실 | 선택 회사의 실적 검증 | 공통 6단계 이동 막대 |
| 종목검증실 | 해당 회사의 판정, 입력 근거 상세 창 | 운영 화면 연결 |
| 결정실 | 네 가지 근거·기록 상세 창, 실제 신규매수 카드가 있는 E의 가격 확인 | 실적실 역방향 이동, 보유 D를 다른 방으로 보내는 버튼 |
| 내 주식 / 신규매수실 | 종목 선택·가격·상태·관련 기사·당시 기록 | 결정실 재이동 |
| 테마뉴스 / 테마 상세 | 동일 테마의 관련 소식과 수치 연결 | 기사 창에서 반복되는 테마 이동 |
| 종목별 성적표 | 동일 종목·평가 회차의 분석 확인 | 기존 성과기록·기존 선정성적 이동 |
| 기록 / 하루 변화 | 같은 종목·날짜의 자료와 이전 기록 | 전체 성적표·다른 테마 화면으로 보내는 일반 링크 |

실적 확인 → 판정 → 대상 종목 가격 확인처럼 직접 이어지는 작업은 유지한다. 모든 링크를 지우거나 각 메뉴를 강제로 독립시키지 않는다. 브라우저 뒤로 가기는 그대로 쓸 수 있다.

## 차트와 데이터

- 사용자가 앞서 요청한 6개월 범위를 적용했다. 기존 캔들·종가선·MA·거래량·확대·날짜별 수치는 유지했다. 기간 버튼은 5일 / 20일 / 6개월이다.
- 예시 최신일 2026-10-16 기준 6개월 범위는 2026-04-17~10-16이다. 현재 날짜를 최신 가격처럼 표시하지 않는다.
- 기존 종가 20개와 가상 OHLCV는 그대로다. 앞선 기간은 날짜만 있는 공백이며 가격이나 거래량을 만들지 않았다. 실제 6개월 데이터 연결은 아직 미완료다.
- 오늘 뉴스는 기존 6건 예시다. 실제 운영 뉴스 332건을 읽거나 연결한 상태가 아니다.
- 성과기록·선정성적·매매 전략·규칙은 v6에서도 운영 화면으로 넘기는 안내뿐이었다. 운영 링크를 없앴으며 이 시안에 상세 자료가 없다는 사실을 표시한다. 실제 규칙·성과를 임의로 복제하지 않는다.

## 동일 입력 검사

`numeric-verification-v7.json`의 검사를 통과했다.

- 종목 7개 전체 객체: v6와 동일. 가격, 판정, 기록, 평가 회차 포함.
- 모든 종목의 테마 대비·시장 대비 점수 동일.
- 공유 방 데이터 전체 동일: 뉴스, 테마, 레인, 후보, 판정 대상, 신규매수 대상, 실적 자료.
- 후보 D/E/F/G, 결정실 D/E/F, 신규매수 E를 그대로 보존.
- OHLCV fixture 파일 동일. 6개월 확장 구간에 수치 없음.
- HTML: 대형 구역 버튼·카드 제거, 17개 주제 보존, 전체메뉴의 홈 링크 없음, 중복 ID 없음, 자산 참조 확인.
- PC·휴대폰 공개 시안 동작 점검은 게시 후 별도 결과를 기록한다. 실제 단말 핀치·운영 데이터는 검사 범위가 아니다.

## 반영 규칙

현재 변경은 my-portfolio의 별도 디자인 시안에만 반영한다. 운영 저장소·데이터·11/10 평가 입력에는 반영하지 않는다.

- 문구·상태·연결 변경이 있으므로 Claude 웹 재검토 대상으로 보낸다. 검토는 사용자가 전달하며, 아스트라는 최종 지침서와 결과를 정리한다.
- 운영 반영 전 번역·추가 후보 로봇 완료를 확인한다.
- 같은 운영 입력에 대한 전후 점수·판정·숫자 보존 증거가 없으면 운영 반영하지 않는다. 이 문서의 가상 데이터 검사를 운영 검증으로 대신하지 않는다.
- 컷라인: 실제 반영 직전의 KST 시각, 원본 데이터 시각, 전후 커밋을 기록한다. 아직 운영 반영 시각은 지정하지 않았다.
- 반영 가능 시간: 수집·판정·평가 작업이 돌지 않는 확인된 시간대에만 시행한다. 현재는 미확정이다.
- 되돌리기: 직전 배포 커밋으로 복구한 뒤 같은 입력 결과·링크·모바일 화면을 확인한다. 수치 차이 또는 대상 종목 누락이 있으면 즉시 중단한다.

v6 원검토는 `REVIEW-v6.md`에 보관한다. v7에 적용되지 않는 1년 범위와 이전 연결 검토는 과거 기록이다.
