# 호쿠토증권 디자인 v2.0 — quest v7.2 수정 지침

2026-10-19 22:52 KST 사용자 정정 반영. 이전 v7 문서보다 이 지침이 우선한다.

## 이번 수정

- 알림홈 → 전체메뉴 연결을 유지한다. 전체메뉴 상단에는 **← 알림홈으로**를 복원해 왕복 이동한다.
- 전체메뉴의 ‘바로 찾기’ 버튼 4개와 ‘오늘 확인’ 행을 제거한다.
- 오늘 뉴스·내 주식은 알림홈에 있으므로 전체메뉴에 중복 배치하지 않는다.
- 하루 변화는 별도 기능이므로 ‘판단 뒤의 결과와 기록’에 옮겨 보존한다.
- 전체메뉴는 후보 검토 순서, 자료·전략, 결과·기록에 집중한다. 나머지 주제별 필요한 연결은 v7의 선별 기준을 유지한다.
- 기존 운영 화면 연결은 복원하지 않는다.

## 범위와 검증

HTML/CSS와 캐시 주소만 수정한다. 종목·기사 데이터, 점수·판정·대상 선정·차트 계산은 변경하지 않는다. v7에서 통과한 동일 입력 검사는 `numeric-verification-v7.json`에 있다. 이번 수정 전후 app.js는 캐시 주소 치환 외에는 동일한지 확인한다.

전체메뉴에는 오늘 뉴스·내 주식을 제외한 15개 주제 입구가 남는다. 하루 변화는 한 곳에만 있다. 삭제한 구역을 가리키는 앵커가 없어야 한다. 알림홈과 전체메뉴의 PC/휴대폰 왕복 이동을 확인한다.

## 남은 제한과 운영 절차

- 실제 운영에는 미반영이다. 문구·연결 변경은 Claude 웹 재검토 대상이며, 사용자가 검토본을 전달한다.
- 차트는 기존 20일 가격과 6개월 범위를 유지한다. 앞선 가격 없는 기간은 공백이다. 운영 뉴스 332건도 아직 연결되지 않았다.
- 성과기록·선정성적·매매 전략·규칙의 상세 운영 자료는 이 시안에 없다.
- 운영 반영 전 번역·추가 후보 로봇 완료, 같은 실제 입력의 점수·판정·숫자 보존을 확인한다. 가상 데이터 검사를 운영 검증으로 대신하지 않는다.
- 컷라인은 실제 반영 직전 KST 시각·입력 시각·전후 커밋으로 기록한다. 반영 가능 시간은 수집·판정·평가 작업이 돌지 않는 확인된 시간대로 지정한다. 현재 운영 반영 시간은 미정이다.
- 문제가 생기면 직전 배포 커밋으로 복구한다. 수치 차이·종목 누락이 있으면 즉시 중단한다. 11/10 평가 입력은 변경하지 않는다.

이전 v7 검토는 `REVIEW-v7.md`에 보관한다. 그 문서의 ‘전체메뉴 홈 연결 제거’와 ‘오늘 확인 행 유지’는 이번 정정으로 폐기한다.
