# 호쿠토증권 문구 검토 — v9-final1020c

모든 자료는 가상입니다. 운영 반영의 증거가 아님. 실행 문구의 원본은 ui-copy.js 한 곳입니다. 이 문서는 검토용 목록입니다.

## 1. 유지하는 문구

- 집중 3개 = 6개월 추세가 플러스인 테마 중, 최근 20거래일 수익이 큰 상위 3개 테마
- ★ 6개 = 테마별 종목들의 최근 20거래일 수익 평균 상위 6개 테마
- 집중 테마가 아님
- 옛 규칙 / 전환일 / 집중 규칙
- 표본 N건
- 확인 필요

집중 테마가 아님은 중립 표시이며 나쁨·제외 판정이 아닙니다. 전환 경계는 display-policy.js 설정을 읽고, 미확인 시각을 확정 문구로 쓰지 않습니다.

## 2. 빈 칸 문구와 판단 근거

| 문구표 위치 | 문구 | 근거 |
|---|---|---|
| templates.focus_waiting | 결과 기다리는 중 (남은 거래일 N일) | 해당 기간 마크 행이 있고 아직 가격이 쌓이는 중 |
| copy.focus.beforeStart | 이 기간은 기록 시작 전 | 해당 신호·기간의 마크 행 자체가 없음 |
| copy.focus.missingPrice | 가격을 못 구함 | 기간 경과와 필요한 가격 누락을 확인 |
| copy.focus.unverified | 확인 필요 | 행 존재·거래일·가격 누락 근거 미확인 |

copy.focus.missingNote는 기존 신호(2026-09-07~10-19)에도 40일 마크가 대기 상태로 생긴다는 설명입니다. 선정일로 40일 기록 대상을 제한하던 문구와 예상일 모순 안내는 삭제했습니다.

## 3. 규칙 구간별 예상일의 단일 원본

옛 규칙은 ui-copy.js의 copy.focus.estimatesLegacy에서 관리합니다.

- basis: 옛 규칙 · 가장 이른 신호 2026-09-07 기준
- first40: 40일 첫 결과는 11/9 전후(추정).
- first60: 60일 첫 결과는 12월 초(추정).

집중 규칙은 ui-copy.js의 copy.focus.estimatesFocus에서 관리합니다.

- basis: 집중 규칙 · 10/20 이후 새 규칙 적용 선정분 기준
- first20: 20일 첫 결과는 11월 중순(추정).
- first40: 40일 첫 결과는 12월 중순(추정).
- first60: 60일 첫 결과는 1월 중순(추정).
- checkpoint: 집중 규칙의 40·60일 결과는 11/10 점검 시점에는 없습니다.

copy.focus.estimateCalendarNote: 예상일은 모두 추정이며, 일본 휴일 반영은 헤르메스가 재확인합니다.

화면의 예상일은 위 두 구간의 문구표에서만 바꿉니다. 옛 규칙과 집중 규칙 화면은 해당 구간 안내만 표시하고, 미확인 전환일 화면은 두 구간의 기준을 각각 명시합니다. 안내 날짜를 전환일 소속, 수익률 계산이나 마크 존재 여부의 근거로 쓰지 않습니다.

## 4. 중복 집계 문구

레인 배정 수는 이벤트(신호) 단위입니다. 종목 성적은 같은 종목·같은 진입일·같은 진입가일 때만 합칩니다. 진입가가 다르면 별도 줄과 templates.same_day_duplicate의 ‘같은 날 중복 N’을 표시합니다.

N은 해당 종목·진입일의 서로 다른 진입가 줄 수입니다. 진입 기준이 없으면 copy.focus.entryUnverified의 ‘진입 기준 · 운영 자료로 확인’을 표시합니다. 신호 수와 종목 성적 수를 같은 숫자로 취급하지 않습니다.

## 5. 한자 규칙과 제목 버튼

한자 금지의 범위: 한국어 UI 문구(버튼·안내·문구표·번역 결과 문장)에만 적용. 일본어 기사 원문 제목, 일본어 회사명·종목명 원문은 예외이며 바꾸지 않는다. 12월 이후 일본어 화면은 별도 문구표라서 이 규칙을 적용하지 않는다.

시안의 일본어 기사 제목은 원래 문장으로 복원했습니다. 원문을 한자 없는 문장으로 바꾸거나 번역 엔진을 수정하지 않습니다.

제목 버튼은 오늘·뉴스룸·테마뉴스·보유 네 곳에만 두고 새 페이지는 한국어로 시작합니다. ‘지금 한국어 · 원문 보기 / 지금 원문 · 한국어 보기’, 번역 차례 대기, 검사 탈락, AI 번역 표시는 유지합니다. 사무실에는 버튼이 없습니다.

## 6. 호출과 승인

JS의 copy·text·tpl, HTML의 data-copy·data-copy-attrs로 같은 문구표를 사용합니다. 판정 비교용 원래 값은 raw로 보존하며 표시 문구를 선정·점수·정렬 입력으로 사용하지 않습니다.

검토 통과 항목은 유지했습니다. 이번 정정 문구와 상태 설명은 범준 확인·Claude 웹 재검토 대상이며, 시안 갱신을 운영 승인으로 취급하지 않습니다.
