# v7.3 문구·번역 관리와 운영 이관 지침

## 이번 시안의 범위

- 로고 도형 유지. HOKUTO 아래 작은 영문 표기는 SECURITIES.
- 알림홈과 뉴스 상세 공통 헤더에 제목 전환 버튼 한 개.
- 현재 표시 모드를 `제목: 한국어` / `제목: 일본어 원문`으로 표시. 버튼은 다음 동작을 접근성 이름으로 안내.
- 알림홈, 뉴스 목록, 분석 카드, 테마의 기사 카드, 기사 상세는 같은 선택을 사용. 이동·새로고침 후에도 제목 모드를 유지.
- 제목 전환은 표시만 변경. 순서·건수·종목 연결·점수·판정·가격은 변경하지 않음. 검색은 두 제목으로 같은 기사를 찾음.

## 번역 문구의 위치

`ui-copy.js`가 **이번에 추가한** 브랜드·제목 버튼·안내 문구의 공통 원본이다. `title-display.js`는 이 원본을 표시한다. 일본어 전환용 가상 제목도 같은 파일의 별도 `demoJapaneseTitles` 항목에 있다.

이 상태가 전체 화면의 문구 통합 완료를 뜻하지 않는다. 기존 HTML, app.js, quest-rooms.js, 상위 메뉴 카탈로그에 이전 한국어 문구가 남아 있다. 운영 이관 시 기존 번역 체계에 맞춰 공통 키로 통합해야 한다. 운영의 번역 체계를 별도로 복제하지 않는다.

### 운영 적용 원칙

1. UI 문구(버튼·메뉴·설명·빈 화면·오류·접근성 이름)는 공통 번역 원본에서 관리한다. 같은 뜻의 문구를 방마다 따로 번역하지 않는다.
2. 기사 제목과 UI 문구를 구분한다. 원문·한국어 번역·원문 언어·번역 상태는 기존 데이터 필드를 그대로 사용한다. 가상 일본어 예시는 운영에 이관하지 않는다.
3. 한국어 번역이 없으면 실제 원문을 유지한다. 이를 번역 완료로 표시하지 않는다. 한국어 원문·영어 원문을 일본어로 새로 번역해 ‘일본어 원문’이라고 표시하지 않는다.
4. 이름·금액·부호·단위·날짜·상향/하향·추정/확정 의미를 보존한다. 표시 제목을 분석 입력이나 후보 선정의 새 입력으로 사용하지 않는다.
5. 이번 문서의 문구 표는 검토용 목록이며, 실행 코드의 문구 수정은 ui-copy.js에서 한다. 운영에서는 기존 승인된 번역 원본에 편입하고 문서 목록을 다시 생성한다.

## Claude 문서 확인 결과

사용자가 전달한 의견과 저장된 확정 기록에서 재검토 조건과 동일 입력 검증 규칙을 확인했다. 명시된 `claude/디자인지침_문구한곳에모으기_20261019.md` 원문 파일 자체는 접근 가능한 검색·자료에서 찾지 못했다. 따라서 위 번역 구현 원칙은 이번 대조 검토에서 정리한 아스트라 지침이며, 그 원문을 직접 검증했다고 주장하지 않는다.

## 운영 반영 전 필수 조건

- 신규 문구·신규 상태가 있으므로 Claude 웹 검토 대상. 검토가 이미 완료됐다는 뜻이 아니다.
- 번역 작업과 추가 후보 로봇 완료를 확인하고, 최종 문구를 확정한 뒤 Hermes/Sigma가 구현.
- 동일한 운영 입력을 고정해 변경 전후 기사 ID/순서/건수, 원문·번역 상태, 종목 연결, 후보, 점수, 판정, 가격·수익률을 비교한다. 제목 모드 전환·모바일·큰 글자에서도 비교한다.
- 운영 비교 결과가 없으면 배포하지 않는다. 시안의 numeric-verification-v73.json은 가상 데이터 보존만 증명하며 운영 검사를 대신하지 않는다.
- 최종 지침서에 실제 컷라인(시각·버전), 배치와 충돌하지 않는 반영 가능 시간, 이전 버전·데이터 연결로 되돌릴 절차를 기록한다. 일정은 운영 담당자가 확인하며 임의로 정하지 않는다.
