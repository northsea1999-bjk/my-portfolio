이번 시안에서 확인할 것

구역은 색으로, 순서는 번호로.

여백과 한글 가독성은 유지하고, 기능마다 다른 색과 선명한 픽셀 아이콘을 적용했습니다.

  1. 색상에 역할 부여

    오늘 뉴스는 파랑, 내 주식은 민트, 하루 변화는 살구색으로 구분했습니다. 검토 단계는 시장·테마, 후보·실적, 판정·가격의 세 묶음으로 연결됩니다. 색은 메뉴를 구분하며 상승·하락이나 추천을 뜻하지 않습니다.

  2. 가벼운 2D 픽셀 표현

    두꺼운 픽셀 아이콘, 각진 모서리, 작은 오프셋 그림자를 사용했습니다. 긴 글과 한글에는 읽기 쉬운 서체를 유지합니다.

  3. PC와 휴대폰에서 같은 검토 순서

    PC는 1→6을 한 줄에 배치하고, 좁은 화면에서는 순서대로 내려갑니다. 휴대폰은 상단 구역 바로가기로 자료와 기록까지 빠르게 이동합니다. 화살표는 자동 통과를 뜻하지 않습니다.

  4. 기능과 판정 연결 유지

    기존 메뉴 15개, 종목별 시안 2개, 기존 입구 2개를 유지했습니다. 보유종목은 내 주식으로 바로 이동하며, 신규매수 확인 대상만 6번의 조건을 확인합니다. BNF는 별도 전략으로 구분합니다.

검토용 문구입니다.

추가·수정 문구와 화면 구성은 Claude 웹 재검토 대상입니다. 운영 반영은 번역·추가 후보 로봇 완료 확인과 동일 입력 비교 증거가 갖춰진 후 진행합니다. 반영 시각·가능 시간·되돌리기 절차는 최종 지침서에 기록합니다. 이 페이지는 별도 시안입니다.
