# 호쿠토증권 v2.0 · 색감 비교 및 최종 점검

2026-10-19 · 아스트라 · 별도 디자인 시안 · 운영 미반영

## 결론

구조를 다시 바꿀 필요는 없다. 중요한 변화 → 전체 뉴스 제목 → 종목 차트 → 근거와 기록의 흐름을 유지한다. 이번 변경은 알림 홈 색의 강약, 차트 1년 범위, 작은 접근성 보완이다.

기존 시안은 `../final-design-20261019/?v=3`에 그대로 보존했다. 이번 `index.html` 위의 ‘RPG 색감 / 기존 색감’ 선택은 같은 화면에서 색만 비교한다. 기존 색감 모드에도 이번 차트와 접근성 보완은 들어 있다. 완전히 이전 구현과 비교하려면 보존된 시안을 사용한다.

## 1년 차트의 정확한 의미

현재 시안에는 종목별 20일치 종가가 있으며 1년 가격 자료는 없다. 1년 버튼은 마지막 자료일을 기준으로 최근 1년의 날짜 범위를 표시한다. 이번 가상 자료에서는 2025-10-17 ~ 2026-10-16이며, 가격이 있는 구간은 2026-09-15 ~ 2026-10-16의 20개 행이다.

앞선 구간은 Lightweight Charts의 `WhitespaceData`로 날짜만 채운다. **가격·거래량을 생성하거나 0으로 채우지 않는다.** 기존 가상 OHLCV 파일은 바이트 단위로 동일하며 종가 배열도 그대로다. 차트 위에 확보된 자료 기간과 빈 구간의 의미를 설명하고, ‘보유한 20일 자료 확대’로 되돌아갈 수 있다. 기본 보기는 20일이다. 유키 메디컬은 계속 자료 없음이다.

1년치 실제 운영 차트를 완성하려면 공급원의 실제 과거 일봉을 연결해야 한다. 마지막 가격 기준일로부터 달력상 1년을 조회하고 거래소 휴일은 공급원 거래일을 따른다. 1년을 무조건 252일로 치환하지 않는다. 분할·배당 조정 기준, 통화와 시간대, 종가 시각을 일치시킨다. OHLCV가 없고 종가만 있다면 종가선만 제공한다. MA5/MA10은 표시 전 기간도 확보해야 첫날부터 계산할 수 있으며, 자료 부족분을 0이나 추정값으로 메우지 않는다. 지표 변화는 판정·후보 선정에 전달하지 않는다.

## 남아 있는 운영 연결 사항

1. 실제 전체 뉴스 건수와 목록 연결. 현재 시안의 6건은 가상이며, 과거 언급된 332건을 고정 숫자로 복제하지 않는다.
2. 1년 가격 및 실제 OHLCV 공급원 연결. 이번 시안의 시가·고가·저가·거래량·날짜는 기존과 동일한 가상 데이터다.
3. 운영 화면으로 연결하는 안내만 있는 목적지는 여전히 안내 화면이다. 19개 목적지 링크를 유지했다고 운영 기능 완성을 뜻하지 않는다.
4. 실제 휴대폰에서 핀치·터치와 모바일 브라우저 확대를 최종 확인한다. 데스크톱 내 좁은 화면 검사는 실기기 검사를 대체하지 않는다.

## 헤르메스/시그마 전달 및 운영 반영 조건

- 사용자 디자인 확인 → 아스트라 최종 지침 → Claude 웹 검토 → 반영 지침에 따라 구현 → 아스트라에 결과 보고.
- 점수·판정·후보 선정·데이터 연결에 닿거나 새 문구·새 상태를 추가하는 수정은 크기와 관계없이 Claude 웹 재검토. **이번 1년 범위 안내와 결측 상태 설명도 포함한다.**
- 같은 입력의 점수·판정·숫자 동일성을 증명하는 결과 없이는 운영 반영 금지. 이번 시안의 검증은 운영 동일 입력 검사나 11/10 수익 평가 검증을 대신하지 않는다.
- 번역과 추가 후보 로봇 완료 확인 전에는 운영 디자인 반영 보류.
- 운영 반영 시간: 배치·평가와 충돌하지 않는 비거래 구간을 헤르메스가 확인 후 기록. 일정 미확인 상태에서 임의 시각을 확정하지 않는다.
- 컷라인: 기존/신규 commit, 자료 스냅샷 시각, 실제 반영 시각(KST/JST), 대상, 비교 결과 기록. 과거 선정·평가 입력 재작성 금지.
- 되돌리기: 기존 표현 파일·차트 의존성 묶음을 보존. 숫자 불일치, 뉴스 누락, 주요 링크 실패 시 표현 파일만 이전 버전으로 되돌린 뒤 동일 입력 재검증. 데이터·평가 기록 삭제 금지.
