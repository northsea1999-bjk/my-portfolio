## 1. 선정 데이터와 표시

운영이 이미 계산한 목록·판정을 받습니다. 화면에서 별도 순위·점수·판정 엔진을 만들지 않습니다.

| 항목 | 전달받을 값과 표시 |
|---|---|
| ★ 주도 6 | 최근 20일 수익 상위 6. 기존 ★·순서 유지 |
| 돈몰림 | 기존 ↗ 및 ↗→★ 전환, 기존 상태·색 유지 |
| 집중 3 | 6개월 추세가 플러스인 테마 중 20일 수익 상위 3. ★ 밖 허용 |
| A·B·C | 집중 3개 테마에서 선정된 종목만. 출처는 실제 레인 표시 |
| D | ★6 + 돈몰림 + 순위 상위 10 테마의 기존 후보. 별도 유지 |
| 홈 출동 3개 | 집중 3개 표시 전용. 실제 매수·수량·비중과 연결하지 않음 |

6개월 추세 계산·동률·유효 자료 부족·순위 상위10의 운영 정의는 기존 작업46 구현을 그대로 사용합니다. 미확인 정의를 시안에서 임의 확정하지 않습니다.

작전실은 집중과 ★를 별도 영역으로 표시합니다. 집중 표식과 ★ 표식은 독립적입니다. 결정실에서 집중에서 빠진 ★를 고장이나 제외 판정으로 보이게 하지 않고 ‘집중 아님’으로 구분합니다. ★ 밖 집중 종목에 ★를 강제로 붙이지 않습니다.

시안 focus-rule.js는 설명용 스냅샷입니다. 선정 코드로 이관하지 않습니다. 가상 명단은 ★상위6·집중상위3·★밖 집중·돈몰림 전환이 함께 보이도록 정리했습니다. 새로 추가한 가상 테마를 실제 운영 테마로 취급하지 않습니다.

## 2. 성과 화면과 과거 기록

메뉴는 **성과기록 / 선정성적** 두 개입니다. 당시 판단 다시 읽기는 성과기록 종목 상세로, 종목별 결과 이어보기는 선정성적 종목 상세로 연결합니다. 메뉴를 다시 늘리지 않습니다.

- 성과 DB에는 규칙 버전 칸이 없습니다. 기존 **선정 날짜**로 `~2026-10-19`와 `2026-10-20~`를 나눕니다. 새 DB 칼럼 추가를 전제하지 않습니다.
- 두 시기의 레인 A·B·C 배정 수 및 LANE_NONE을 한 숫자로 합치지 않습니다. 새 규칙 UI의 기본값은 10/20 이후입니다.
- 당시 테마·레인·집중 여부는 기존 선정 기록 또는 당시 스냅샷과 연결합니다. 현재 명단을 과거에 소급하지 않습니다. 값이 없으면 확인 필요로 남깁니다.
- 시안의 `ruleVersion`은 화면 필터 상태 이름입니다. DB 규칙 버전 필드가 아닙니다. 실제 분기는 날짜로 처리합니다.
- 알림홈 성적표는 새 시기 집중에서 ABC로 선정된 회차만. D-only는 제외하고 ABC/D 중복은 동일 회차에서 한 번 표시. 다른 날짜에 재선정된 별도 회차는 섞지 않습니다.

| 기본 칸 | 기존 기록 | 없는 경우 |
|---|---|---|
| 1개월 | 20거래일 | 결과 기다리는 중 |
| 2개월 | 40거래일, 10/21 추가 예정 | 결과 기다리는 중; 첫 결과 11/9 무렵 추정 |
| 3개월 | 60거래일 | 결과 기다리는 중; 첫 결과 12월 초 추정 |

개월은 보기 이름이고 실제 기록 일수도 칸 제목에 함께 표시합니다. 달력 날짜로 새 성과를 계산하지 않습니다. 1·5일은 접힌 영역으로 보존합니다. 표본 수·완료 수는 작은 안내로 표시하고, 아직 없는 40·60일 수익을 0%로 만들지 않습니다.

실제 분할 가격 교정 후 5일 평균이 약 −1.05%로 바뀌었다는 전달 사항은 운영 DB 결과를 그대로 쓰는지 확인할 항목입니다. 가상 수익률을 실제 교정값으로 덮어쓰지 않습니다. 모든 예시 숫자에는 가상 표시를 유지합니다.

하루 변화는 알림홈 한 곳입니다. 집중 3개 변화가 가장 위에 옵니다. 전후 스냅샷이 있을 때 진입·이탈을 비교하고, 이전 자료가 없으면 교체 수를 만들지 않습니다. 시안에는 실제 이전 집중 명단이 없어 첫 적용 상태로 표시했습니다.

- 매수 금액·비중·주식 수·주문 기능을 추가하지 않습니다. 텔레그램 위험 알림도 이번 화면 범위가 아닙니다.
