- 전체메뉴 결과 구역: **성과기록 / 선정성적 두 개만**. 종목별 상세는 해당 화면 안에서 열림.
- 성과기록·선정성적: `★6 · ~10/19` / `집중3 · 10/20~` 분리, 1·2·3개월 칸. 새 규칙 아래에서는 전체/ABC/D 출처 선택 가능.
- 알림홈 성적표: **집중 테마에서 A·B·C로 선정된 회차만**. D만 선정된 종목 제외, A·B·C와 D 중복은 동일 회차에서 한 번 표시. 세 테마라는 뜻이며 실제 선정 종목 수를 3개로 제한하는 규칙은 없음.
- 하루 변화는 알림홈 한 곳에 배치. 첫 적용일 예시는 `집중 3개 적용 시작`을 우선 표시. 이전 집중 명단이 없으므로 교체 건수를 만들지 않음.

## 예시 자료와 보존 범위

- **실제 10/20 집중 테마·선정 종목은 아직 미연결**. `focus-rule.js`의 테마, 6개월 추세 부호, 선정 회차는 명시적인 가상 표시 스냅샷이다. 운영 선정 엔진이 아니다.
- 가상 명단은 ★ 6개와 ★ 밖 포함 집중 3개를 동시에 설명하도록 구성했다. 기존 종목 7개의 가격·20일 종가 배열·판정·과거 기록·평가값, 기사, 후보와 기존 레인 D 명단은 보존했다.
- 새 규칙 선정 예시는 10/20, 가격·뉴스·기존 분석은 10/16 자료다. 새 회차 상세에는 분석 미연결을 표시하며 10/16 분석을 10/20 분석으로 바꾸지 않는다.
- 새 규칙 1·2·3개월은 `평가 대기`. 과거 기간 자료가 없으면 `자료 없음`. 기존 20거래일 평가를 1개월 성적으로 바꾸지 않고 과거 규칙 아래 별도 보존.
- 홈 성적표는 선택된 **회차의 규칙 ID·집중 여부·레인 출처**로 필터링한다. 현재 집중 명단을 과거에 소급 적용하지 않는다.

## 운영 연결 계약

1. 운영이 산출한 ★6 목록, 집중3 스냅샷, 대상 테마 전체 범위, 기준 시각을 받는다. 화면에서 선정을 다시 계산하지 않는다. 6개월 추세의 정확한 계산 정의·동률 처리·유효 후보 부족 처리는 기존 운영 규칙을 사용한다.
2. 선정 회차마다 `rule_version`, `selected_at`, `theme_at_selection`, `focus_at_selection`, `star_at_selection`, `lanes_at_selection`, 종목 ID를 보존한다. ★ 밖 여부도 당시 값으로 표시한다.
3. D 명단은 기존 범위를 유지한다. 성적표 제외는 **홈 ABC 보기의 표시 필터**일 뿐, D 후보의 삭제나 운영 판정 변경이 아니다.
4. 1·2·3개월의 시작 가격·종료일·휴장일 처리·분할 조정·시장/테마 비교값은 승인된 운영 정의와 결과를 받는다. 20/40/60거래일로 임의 변환하지 않는다.
5. 집중 명단의 진입·이탈은 전후 두 스냅샷이 있을 때만 알림홈에 표시한다. 첫 적용일·자료 없음·명단 유지와 교체를 구분한다.
6. 신규 UI 문구는 `ui-copy.js`의 `copy.focus`가 공통 원본이다. 운영 번역 원본에 편입하며 가상 자료와 예시 종목은 이관하지 않는다.
