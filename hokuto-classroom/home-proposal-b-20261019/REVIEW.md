# 호쿠토증권 디자인 v2.0 · 알림 홈 시안 B

2026-10-19 / 별도 검토 시안 / 운영 미반영

## 화면 목적

전체메뉴가 기능의 안내도라면, 알림 홈은 오늘 먼저 확인할 변화를 보여주는 입구다. 전체메뉴 시안 B의 픽셀 아이콘·작은 책상 그림·각진 카드·구역별 색을 이어 쓴다.

- 상단: 종목 검색, 주요 메뉴, 예시 자료 기준일.
- 첫 화면: 먼저 확인할 변화와 오늘 뉴스 제목을 PC에서 나란히 배치한다.
- 변화: 보유 경고는 노랑, 신규 후보 변화는 보라, 후속 뉴스는 파랑. 문구와 판정은 기존 시안 그대로다.
- 뉴스: 전체 건수·제목·나머지 제목 펼치기·전체 뉴스룸을 유지한다. 운영 뉴스 건수 332 등을 고정 입력하지 않는다.
- 종목: 민트색 영역에서 기존 7개 가상 종목의 보유 점검과 결정실 판정을 구분해서 표시한다.
- 상세: 종목을 선택한 뒤 현재 분석·변화 기록·성적표를 보여준다. 초기 화면에서 한 종목의 긴 상세가 전체 현황과 경쟁하지 않게 했다.
- 연결: 알림 홈 ↔ 전체메뉴 시안 B. 뉴스 → 기사 내용·연결 근거 → 회사 분석과 기록의 기존 동작을 재사용한다.

## PC와 휴대폰

PC에서는 상단 가로 메뉴와 두 열 배치를 사용한다. 휴대폰에서는 한 열, 구역 바로가기, 하단 5개 주요 메뉴를 사용한다. 검토용 PC/휴대폰 전환은 iframe의 실제 뷰포트를 변경하므로 기존 미디어 쿼리와 상세 화면 전환도 함께 작동한다.

## 구현 범위

`home.html`은 기존 DOM과 요소 ID를 유지하고 배치와 장식을 조정한 별도 페이지다. 기존 `stock-home.js`, `stock-rooms.js`, `stock-links.js`를 수정 없이 공유한다. `home-pixel.js`는 장식 SVG와 구역 스크롤만 처리한다. 가격, 점수, 판정, 후보 선정, 뉴스 연결 로직을 새로 만들거나 변경하지 않았다.

기존 전체메뉴 시안 B에서는 브랜드와 ‘알림 홈’ 링크만 새 홈으로 연결했다. 19개 기능의 목적지는 유지한다.

## 검토 및 적용 조건

새 구역 설명, 상세 노출 방식과 메뉴 연결 변경은 Claude 웹 재검토 대상이다. 사용자 디자인 확인 후 아스트라가 최종 지침을 작성한다.

운영 반영은 번역과 추가 후보 로봇 완료 확인 후 진행한다. 같은 입력으로 점수·판정·숫자가 그대로임을 입증한 검사가 없으면 운영에 반영하지 않는다. 실제 반영 단계에서는 허용 시간, 반영 시각(컷라인)·버전, 되돌리기 절차를 기록한다. 가상 시안 검사는 운영 데이터의 동일성 검사나 2026-11-10 평가 검사를 대신하지 않는다.

- 스크립트 구문 검사와 참조 파일 존재 확인 통과.

- 새 알림 홈 → 전체메뉴 B → 새 알림 홈 왕복 확인.
- 화면 기록: `proposal-desktop.jpg`, `proposal-mobile.jpg`.
