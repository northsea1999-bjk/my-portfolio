# 북두증권 학원 · 사무실 연습

선생님께 설명할 목표: “픽셀 캐릭터가 움직이는 증권사 사무실을 만들고, 방이나 버튼을 누르면 정보를 쉽게 볼 수 있게 한다.”

## 실행과 첫 수정

`index.html`을 두 번 클릭해 브라우저에서 엽니다. 설치나 서버는 필요 없습니다. 전체 화면 예시는 `preview.png`에 있습니다. 처음 수정은 `index.html`에서 `리서치센터` 같은 방 이름을 찾아 글자 하나를 바꾸고 새로고침하세요. 이어서 방의 `▶ 브리핑` 버튼을 눌러 예시 창을 열고 `닫기`로 닫아 보세요. 버튼 문구는 같은 파일, 창 내용은 `script.js`의 `examples`, 색·빛·깊이감은 `style.css`에서 바꿉니다. 동작 확인은 파일 주소 끝에 `?check`를 붙이고 브라우저 개발자 도구 콘솔의 `학원 화면 확인 완료` 문구를 봅니다.

수업 순서: 사무실 배치(`index.html`) → 색상·빛·깊이감(`style.css`) → 캐릭터 움직임(`style.css`의 `stroll`·`bounce`, `script.js`의 `actors`) → 버튼·팝업(`index.html`의 `data-room`, `script.js`의 `openExample`).

첫 과제: 방 이름이나 안내 문구 하나를 바꾸고, 버튼 하나로 학원용 예시 팝업을 열고 닫기. 디자인은 수업에서 완성합니다. 지금 화면은 최종 HD-2D 디자인이 아닙니다.

## 원본과의 대응 (나중에 별도 적용)

| 학원 파일 | 실제 북두증권 원본의 대응 부분 |
|---|---|
| `index.html`의 층·방·버튼 | `hokuto/screen/office_v8_template.html`의 `room-news`, `room1`~`room5`, `.tag`, 브리핑/방 열기 버튼 |
| `index.html` 안의 `sd-*` 캐릭터 그림 | 같은 템플릿의 SVG `<defs>`에서 필요한 캐릭터만 발췌 (복사본) |
| `style.css`의 벽·빛·움직임 | 같은 템플릿의 사무실 CSS와 캐릭터 애니메이션 (학원용으로 단순화) |
| `script.js`의 `actors`, `openExample` | 같은 템플릿의 `CAST`·`MASCOTS`, `openBrief`·`openRoom` (실제 기능 대신 가상 예시) |

운영 화면은 `hokuto/screen/build_office_v8.py`가 원본 템플릿에서 다시 만듭니다. 수업 결과를 북두에 적용할 때는 별도 승인 작업으로 원본 템플릿·그림·동작을 수정해야 합니다. 생성된 HTML만 덮어쓰면 다음 생성 때 사라집니다.

이 폴더는 실제 계좌·보유 내역·기사·주가·사설 서버·매매 신호를 포함하지 않습니다. 모든 팝업은 학원용 가상 예시이며 기존 개인 포트폴리오 과제와 독립입니다.
