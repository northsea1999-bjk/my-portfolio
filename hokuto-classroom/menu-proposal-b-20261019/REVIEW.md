# 호쿠토증권 디자인 v2.0 · 전체메뉴 시안 B

2026-10-19 / 아스트라 구성 제안 / 운영 미반영 / Claude 웹 재검토 전

## 이번에 바꾼 점

| 항목 | 구성 |
|---|---|
| 연결성 | 오늘 확인 / 종목 검토 / 자료·전략 / 결과·기록의 네 구역 바로가기. 기존 메뉴 목적지는 유지. |
| 구조 | 오늘 점검 3개 → 새 후보 검토 6단계 → 참고 자료와 사후 기록. 보유종목은 내 주식으로 바로 이동. |
| 색감 | 뉴스 파랑, 보유종목 민트, 하루 변화 살구. 검토 단계는 파랑·보라·노랑의 세 묶음. 자료는 세이지, 기록은 피치. |
| 그래픽 | 32 단위 SVG 픽셀 아이콘, 작은 연구 책상 그림, 각진 카드, 짧은 오프셋 그림자. |
| 글자 | 한글은 일반 가독성 서체. 주요 메뉴는 PC 18~19px, 휴대폰 17~18px. 번호와 짧은 표식만 고정폭 서체. |
| 반응형 | 넓은 PC는 검토 순서를 한 줄로, 중간 폭에서는 두 열, 휴대폰에서는 세로로 배치. 상단 구역 바로가기 유지. |

색은 구역 구분에만 사용한다. 상승·하락, 추천, 판정, 통과 여부를 뜻하지 않는다. 번호는 확인 순서이며 자동 통과나 완료 상태를 뜻하지 않는다. 매수대상 선정과 진입 신호는 다르며, 신규매수실은 해당 확인 대상만 이용한다. BNF는 별도 전략이다.

## 유지한 기능

기존 메뉴 15개, 종목별 시안 2개, 기존 입구 2개를 각각 한 번 배치했다. 오늘 뉴스의 전체 제목 진입점을 유지했다. 뉴스 건수는 이 메뉴에서 임의로 고정하지 않았다. 기존 목적지, 판정 로직, 투자 데이터, 운영 사이트는 변경하지 않았다.

## 추가·수정한 화면 문구와 동작

- 네 구역 바로가기와 설명, 시안 B의 변경 의도.
- ‘어제와 무엇이 달라졌나요?’ → ‘무엇이 달라졌나요?’: 전 거래일과 비교한다는 기존 설명 유지.
- 신규매수 카드 설명: ‘대상 종목의 가격·진입 조건’.
- 페이지 하단에서 색의 역할을 설명.
- 검토용 도구: PC / 휴대폰 전환, 360·390·430px 너비 선택. 투자 상태나 서비스 판정 상태가 아니다.

## 적용 전 규칙

이 페이지는 확정 지침서나 운영 적용 승인이 아니다. 새 문구와 새 화면 상태가 있으므로 Claude 웹 재검토로 보낸다. 점수·판정·후보 선정·데이터 연결에 닿는 변경은 크기와 무관하게 재검토 대상이다.

실제 구현 지침에는 반드시 같은 입력으로 기존·수정본을 비교하여 점수·판정·숫자의 동일성을 입증하는 검사를 포함한다. 이번 별도 메뉴 시안의 목적지 일치 검사는 그 증명을 대신하지 않는다. 해당 증거가 없으면 운영에 반영하지 않는다.

번역과 추가 후보 로봇의 완료를 모두 확인한 뒤 운영 반영을 진행한다. 반영 전 허용 시간을 확정하고, 실제 반영 시각(컷라인)·버전 및 되돌리기 절차를 최종 지침에 기록한다. 2026-11-10 수익 평가에 영향을 주는 판정·데이터 변경을 디자인 변경과 혼합하지 않는다.

## 확인 결과

- 19개 메뉴 누락·중복 없음.
- 시안 A와 모든 메뉴의 목적지 URL 일치.
- 검토 순서: meeting → ops → strategy → recommend → decision → newbuy.
- 구역 바로가기 4개와 SVG 아이콘 참조 정상.
- JavaScript 구문 검사 통과.
- PC에서 가로 넘침과 주요 메뉴 글자 잘림 없음. 6단계가 같은 행에 1~6 순서로 배치됨.
- 휴대폰 미리보기 360·390·430px에서 가로 넘침 없음. 모든 단계가 같은 열에서 번호순으로 이어짐.
- 휴대폰 구역 바로가기 클릭 시 상단 메뉴가 고정되고 대상 제목이 가려지지 않음.
- ‘뉴스’ 검색 시 오늘 뉴스와 테마뉴스 2개 결과 표시. 검색 초기화 후 전체 19개 메뉴 복원.
- 검색 결과에서 오늘 뉴스를 열어 가상 뉴스 6개를 보여주는 기존 뉴스룸으로 연결되는 것을 확인.
- 변경 의도 대화상자와 이전 시안 비교 링크 확인.
- 검증 범위: 브라우저의 반응형 미리보기. 실제 iOS·Android 기기 검사는 미실시.
