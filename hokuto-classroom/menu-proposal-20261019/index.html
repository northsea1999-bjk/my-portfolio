이번 시안에서 확인할 것

방 이름보다, 할 일을 먼저.

처음 보는 사람도 입구를 고르고 다음 화면을 예상할 수 있게 구성했습니다.

  1. 오늘 점검과 새 후보 검토를 분리

    보유종목을 확인하는 사람에게 6단계를 다시 거치게 하지 않습니다.

  2. 읽는 순서를 실제 배치로 표현

    PC는 1→2→3→4→5→6, 휴대폰은 1번부터 세로로 이어집니다. 화살표는 검토 순서이며 자동 통과를 뜻하지 않습니다.

  3. 굵은 아이콘 + 쉬운 설명 + 기존 이름

    참고 이미지처럼 아이콘과 글자를 또렷하게 하고, 기존 방 이름도 함께 남겼습니다.

  4. 기능을 합치거나 삭제하지 않음

    기존 메뉴 15개, 종목별 시안 2개, 기존 입구 2개를 모두 배치했습니다. BNF는 별도 전략으로 구분했습니다.

검토용 문구입니다.

새 설명 문구는 Claude 웹 검토 후 확정합니다. 운영 반영 보류와 동일 입력 비교 규칙은 그대로 적용합니다. 기존 시안과 운영 화면은 수정하지 않았습니다.
