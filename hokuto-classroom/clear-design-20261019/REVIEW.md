# 호쿠토증권 v2.0 · 화면별 역할 단순화 지침

2026-10-19 · 아스트라 · 사용자 요청에 따른 수정 시안 · 운영 미반영

## 결론과 변경 원칙

이전 시안은 홈에 알림·뉴스·종목·차트·전체메뉴 안내를 모두 놓고, 방마다 다른 방으로 이어지는 버튼을 반복했다. 처음 보는 사용자가 현재 위치와 확인 목적을 잃기 쉬웠다. 이번에는 ‘화면 하나에서 한 가지 일을 끝낸다’로 바꿨다.

- 알림 홈: 변화 3건만 표시. 알림은 다른 화면으로 이동하지 않는다. ‘자세한 내용’과 ‘근거 문장 보기’는 같은 카드에서 펼쳐진다. 뉴스 목록·종목 목록·차트·바로가기·다음 방 안내를 제거했다.
- 전체메뉴: 알림 홈 / 오늘 뉴스 / 내 주식 / 후보 판정 / 가격 차트 / 기록·성적의 6개 입구. 기존 나머지 도구 14개는 기본 접힘 상태의 ‘추가 도구’에 보존했다. 읽는 순서 화살표나 6단계 이동 지도는 제거했다.
- 모든 화면: 위에 현재 위치와 ‘알림 홈 / 전체메뉴’만 둔다. 다른 업무를 시작할 때는 전체메뉴로 돌아온다.
- 뉴스: 제목 → 같은 화면의 기사 상세. 기사 상세에서 회사·테마·다른 방으로 나가는 버튼을 제거했다. 전체 뉴스 6건은 유지했다.
- 내 주식: 보유 4종목의 상태·경고·다음 확인. 이 화면의 차트와 다른 방 바로가기는 제거했다.
- 후보 판정: 기존 결정실 3종목을 그대로 유지한다. 판정 근거는 카드 안에서 펼친다. 실적·가격·기록으로 보내는 연속 이동 버튼은 제거했다.
- 기록·성적: ‘당시 기록 / 선정 성적’ 두 항목은 같은 업무의 선택으로만 유지한다. 기록의 입력 자료는 같은 화면의 대화창에서 읽는다.
- 가격 차트: 별도 화면에서 종목과 기간을 선택한다. 분석·기록으로 나가는 버튼은 없다.

추가 도구는 기존 19개 목적지를 보존하기 위한 보조 입구다. 핵심 6개와 중복되는 원래 5개 목적지(뉴스·보유·결정·기록·성적)를 제외한 14개가 접힘 영역에 있다. 운영 연결 안내만 있던 목적지는 여전히 안내이며 기능을 구현한 것으로 주장하지 않는다.

## 필수 / 선택 / 불필요

|구분|작업|
|---|---|
|필수|홈의 역할 분리, 반복 이동 제거, 현재 위치 표시, 실제 뉴스 전체 목록 유지, 가격·판정·후보 동일성 검증|
|필수|운영 6개월 차트에 실제 과거 가격을 연결하고 데이터 기준일과 결측을 표시|
|선택|사용 빈도가 확인된 뒤 추가 도구의 배치 조정|
|불필요|모든 카드에 관련 방 링크, 단계별 연속 이동, 홈에 전 기능 요약 중복 배치, 추가 장식·알림 상태 도입|

이번 변경은 읽기 쉬운 정보 구조를 위한 표현 변경이다. 기존 방의 판정 역할을 합치거나 계산을 통합하지 않는다. ‘후보 판정’은 기존 결정실의 표시 이름이며 매수대상·보류·제외 기준을 바꾸지 않는다.

## 6개월 차트

1년 버튼을 6개월 버튼으로 바꿨다. 기본 20일 보기와 6개월 범위를 제공한다. 자료가 부족한 시안에서는 기본 20일을 사용해 차트 가독성을 유지한다.

현재 공개 시안의 가상 종가는 20일치뿐이다. 마지막 자료일은 2026-10-16이므로 6개월 범위는 **2026-04-17 ~ 2026-10-16**이다. 가격이 있는 구간은 2026-09-15 ~ 2026-10-16의 20행이다. 앞선 기간은 날짜만 있는 빈 구간으로 표시하며 과거 가격·거래량을 만들어 넣지 않는다. ‘현재’는 화면의 실제 자료 기준일이며 브라우저 오늘 날짜로 오래된 자료를 최신처럼 표시하지 않는다.

따라서 **6개월 기간 선택 구현과 6개월치 가격 데이터 확보는 별개**다. 이번 작업으로 실제 6개월치 가격이 확보됐다고 보고하지 않는다. 현재 예시는 실제 종목 코드가 없는 DEMO 종목이므로 실제 시장 가격과 이어 붙이지 않는다.

헤르메스/시그마 운영 구현 시에는 기존 가격 공급원의 실제 종목별 일봉을 마지막 가격 기준일에서 달력상 6개월 전까지 조회·저장한다. 6개월을 고정 120일·126거래일로 대체하지 않는다. 거래소 휴일·통화·분할 및 배당 조정 기준·가격 기준 시각을 기존과 맞춘다. OHLCV가 없고 종가만 있으면 종가선만 표시한다. 지표의 앞부분 계산이 필요하면 해당 이전 기간을 추가 확보하고, 가격 없는 날을 0이나 보간 가격으로 채우지 않는다. 데이터 연결이 판정·후보 계산에 영향을 주지 않게 한다.

## 코드와 검증 경계

- `app.js`: 기존 종목·기록·점수 계산은 그대로. 홈 알림과 표시 호출만 수정.
- `simple-rooms.js`: 기존 방 데이터의 별도 복사본. 뉴스·후보 명단·실적·테마 자료 동일. 교차 이동 버튼을 축소하고 보유 화면의 중복 차트 제거.
- `simple-ui.js`: 현재 위치 표시, 불필요한 이동 버튼 제거, 카드 안 근거 표시.
- `menu.html`, `simple.css`: 6개 주 입구와 접힌 추가 도구, 공통 이동.
- `chart.html`, `chart-page.js`, `stock-data.js`, `chart-style.css`, `broker-charts.js`: 독립 차트와 6개월 범위.
- `chart-fixture.js`: 이전 파일과 바이트 단위 동일. 기존 시가·고가·저가·거래량·날짜는 디자인용 가상 자료다.

`numeric-verification.json`에 7개 종목 객체 전체, 점수 계산, 뉴스·후보·테마·실적 자료의 동일성 및 결측 보존을 기록했다. 특히 후보 명단 D/E/F/G, 결정실 D/E/F, 신규매수 E를 그대로 유지했다. 명칭이나 메뉴 수를 줄였다는 이유로 후보를 재선정하지 않았다.

## 검토와 운영 반영

사용자 시안 확인 → 아스트라 최종 지침 → Claude 웹 검토 → 반영된 지침으로 헤르메스/시그마 구현 → 아스트라에게 결과 보고.

새 문구·새 상태, 점수·판정·후보·데이터 연결에 닿는 수정은 크기에 관계없이 Claude 웹 재검토 대상이다. 이번 메뉴 문구·알림 설명·6개월 안내도 포함한다. 같은 운영 입력에서 점수·판정·숫자 동일성을 증명한 결과 없이는 운영 반영하지 않는다. 이번 가상 시안 검사는 11/10 수익 평가 검사를 대신하지 않는다.

번역과 추가 후보 로봇 완료 확인 전에는 운영 디자인 반영을 보류한다. 운영 배치·평가와 충돌하지 않는 비거래 시간 구간을 확인한 뒤 기존/신규 commit, 입력 스냅샷, 실제 반영 시각(KST/JST), 적용 대상과 비교 결과를 컷라인으로 기록한다. 문제 발생 시 보존한 이전 표현 파일·의존성으로 되돌리고 다시 검증한다. 과거 평가·선정 데이터는 삭제하거나 다시 쓰지 않는다.
