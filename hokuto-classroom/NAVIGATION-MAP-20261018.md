# 알림 홈과 기존 호쿠토의 연결

작성: 2026-10-18. 범위는 `my-portfolio` 디자인 미리보기다. 운영 서버·판정·자료는 변경하지 않는다.

## 기본 방향

새 첫 페이지는 알림 홈이다. 상세 확인은 기존 호쿠토 메뉴의 역할을 따른다. 기존 화면을 합치거나 새 이름으로 대체하지 않는다. 기존 첫 페이지의 색상·배치를 유지하고 메뉴와 이동 경로를 수정했다.

기존 메뉴 대조 근거는 이전에 확보한 사무실 HTML 사본의 상단 12개 링크(빌드 표시 `20261011083018`)와 기존 `plan.html`의 기능 대응표다. 현재 운영 서버의 최신 메뉴 전체를 직접 재확인한 것은 아니다. `ko/today.html`은 사용자가 제공한 현재 오늘 화면의 경로다. 12개 링크와 오늘·사무실 입구를 보존하며, 이를 현재 운영 빌드의 ‘14/14 검증’으로 표현하지 않는다.

## 알림 → 상세 확인 → 복귀

| 새 홈의 진입점 | 미리보기 도착 화면 | 이어서 보는 곳 |
|---|---|---|
| 보유종목 새 경고 | 보유주식 관리, 해당 가상 종목 선택 | 종목 분석·기록, 관련 뉴스 |
| 신규 후보 진입 | 결정실, 해당 가상 종목 강조 | 선정 근거, 신규매수 |
| 뉴스 후속 확인 | 뉴스룸, 해당 가상 기사 강조 | 기사 근거 → 종목 분석·기록 |
| 왼쪽·하단 내 주식 | 보유주식 관리 | 기존 보유주식 관리 열기 |
| 왼쪽·하단 결정실 | 결정실 | 기존 결정실 열기 |
| 전체 메뉴 | 기존 메뉴 12개를 각각 표시 | 미리보기 또는 실제 기존 화면 |

## 기존 메뉴 대응표

실제 연결 주소는 사용자가 입력한 호쿠토 기본 주소 뒤에 아래 경로를 붙인다. 한국어 화면 주소를 입력하면 `/ko/`를 유지하고, 옛 화면 주소를 입력하면 원래 경로를 유지한다. 오늘·사무실 입구는 각각 지정된 경로로 연결한다. 공개 코드에는 사설 서버 주소를 넣지 않는다.

| 기존 메뉴 | 경로 | 이 시안의 동작 |
|---|---|---|
| 뉴스 / 뉴스룸 | `news_board.html` | 기사·근거·종목 연결 미리보기 + 기존 화면 |
| 테마뉴스 | `theme_news.html` | 테마별 기사 미리보기 + 기존 화면 |
| 리서치 | `hokuto_today.html` | 테마·구성 종목 미리보기 + 기존 화면 |
| 추천 | `recommend.html` | 후보 조건 미리보기 + 기존 화면 |
| 북두테마 | `research_new.html` | 기존 화면 연결; 추천과 합치지 않음 |
| 결정실 | `decision_room.html` | 판정·근거·종목 연결 미리보기 + 기존 화면 |
| 사장실 · 놀이공원 | `hokuto_fun.html` | 변화 비교 미리보기 + 기존 화면 |
| BNF 신호 | `bnf_signal.html` | 별도 전략 미리보기 + 기존 화면 |
| 보유주식 관리 | `holdings_room.html` | 보유 종목만 표시 + 기존 화면 |
| 신규매수 | `newbuy_room.html` | 신규 후보만 표시 + 기존 화면 |
| 성과기록 | `performance_room.html` | 기존 화면 연결; 선정성적과 합치지 않음 |
| 선정성적 | `selection_results.html` | 기존 화면 연결; 성과기록과 합치지 않음 |

기존 입구 두 개도 별도로 둔다: 오늘 화면 `ko/today.html`, 사무실 `hokuto_main.html`.

`종목별 변화·기록`과 `종목별 성적표`는 새 홈의 가상 디자인 시안으로 구분한다. 운영 기록 저장 기능이 구현됐다는 뜻이 아니다. 세부 운영 자료가 확인되지 않은 메뉴는 숫자를 만들어 채우지 않고 기존 화면을 여는 연결 화면으로 구성한다.

## 이동 규칙

- 내부 이동에는 ‘이전 화면·알림 홈·전체 메뉴’를 공통으로 둔다.
- 뉴스 필터·종목·기록 날짜·읽던 세로 위치를 출발 상태로 보존한다. 종목 분석에서 출발 화면으로 복귀하거나 브라우저 뒤로/앞으로 이동할 수 있다.
- 실제 호쿠토는 새 탭으로 열어 미리보기의 읽던 상태를 보존한다. 실제 서버 화면 안에 새 공통 메뉴를 설치한 것은 아니다.
- 가상 `DEMO-*` 종목이나 필터를 실제 서버 주소에 넘기지 않는다. 운영 화면의 종목별 직접 주소 규칙은 이번에 확인하지 않았기 때문이다.
- ‘내 호쿠토 연결’에서 입력한 주소는 브라우저에만 저장한다. 뉴스·계좌 자료를 가져오거나 서버에 쓰지 않는다.
- 이전 주소의 `manager`, `trading`, `space`는 각각 추천, 신규매수, 기존 사무실로 이어진다. 보유 종목의 진입·보유 버튼은 보유주식 관리로 분기한다.

## 검증과 한계

`node hokuto-classroom/tests/navigation-connections.test.cjs`로 원본 12개 메뉴 경로, 16개 화면 경로, 알림 3개 도착지, 날짜·필터·스크롤 복귀, 뒤로/앞으로 이동, 연결 주소 처리와 이전 주소 호환을 확인했다. 화면 폭 분기 로직도 함께 확인한다. 이 검사는 브라우저 없는 상태 검사이며 실제 렌더링 검사가 아니다.

원래 홈 CSS가 변경되지 않았고 HTML의 ID 중복 및 자산 경로 누락이 없음을 확인했다. 모바일 대응 CSS를 포함하지만 이번 환경에서는 지원되는 브라우저 미리보기 기능이 없어 실제 화면 캡처·배치 검수는 수행하지 못했다. 운영 서버 링크의 현재 응답·접속 권한도 확인 필요다.
