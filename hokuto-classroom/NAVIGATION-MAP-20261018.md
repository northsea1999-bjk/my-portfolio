# 알림 홈과 기존 호쿠토의 연결 — v7

2026-10-18. `my-portfolio`의 공개 디자인 미리보기만 수정했다. 운영 서버·판정 계산·뉴스 처리·보유 자료에는 쓰지 않았다. 화면 자료는 기존 가상 예시다.

## 이번에 바꾼 것

- ‘자주 확인하는 곳’과 큰 이동 설명 배너를 없앴다. 같은 운영 메뉴는 전체 목록에 한 번씩만 나온다.
- 기존 기능 13개를 내 종목과 판정 / 뉴스와 후보 / 변화와 성과 / 전략과 규칙으로 배치했다. 묶음은 찾기 위한 분류이며, 반드시 차례대로 통과해야 하는 절차가 아니다.
- 현재 한국어 화면의 이름을 우선하고, 북두테마·추천·보유주식 관리·트레이딩룸이라는 익숙한 이름도 보조 표기와 검색으로 유지했다.
- 리서치센터와 작전실의 잘못된 대응을 고쳤다. 리서치센터는 `research_new.html`, 작전실은 `hokuto_today.html`이다.
- 이전 시안에 없던 `trading_logic.html` 연결을 ‘트레이딩 상황실’로 추가했다. 신규매수와 별개다.
- 화면 위의 중복 이동 메뉴를 줄였다. 공통 ‘이전 화면·알림 홈·전체 메뉴’는 유지하고, 내용을 읽은 뒤 필요한 자료로 이어지도록 배치했다.
- 펀드매니저실 → 결정실 → 보유관리 또는 신규매수에서 같은 종목을 유지한다. 보류 종목은 신규매수로 보내지 않는다.

위 확인은 저장소의 연결 계약을 확인한 것이다. 현재 서버의 생성 파일·응답·실제 화면 클릭을 직접 확인한 것은 아니다. 소스의 한국어 화면 14개 중 ‘오늘’은 기존 입구로, 나머지 13개는 기능 메뉴로 둔다. 옛 사무실 입구는 추가 보존한다. 이를 운영의 생성 성공 ‘14/14’ 검증으로 표현하지 않는다.

메뉴 타일은 가상 미리보기 또는 연결 안내를 연다. 오른쪽 ↗는 실제 화면을 새 탭에서 연다. 기존 입구는 오늘(`ko/today.html`)과 사무실(`hokuto_main.html`)이다.

‘종목별 변화·기록’, ‘종목별 성적표’는 별도의 새 홈 디자인 시안이다. 운영 기록 저장·분석 기능이 추가됐다는 의미가 아니다.

## 종목을 이어 보는 규칙

| 시작 | 동작 | 도착 |
|---|---|---|
| 보유 경고 알림 | 해당 종목 선택 | 내 주식 |
| 새 후보 알림 | 해당 종목 강조 | 결정실 |
| 후속 뉴스 알림 | 해당 기사 강조 | 뉴스룸 |
| 펀드매니저실 후보 | 입력된 종목만 판정 버튼 활성화 | 같은 종목의 결정실 |
| 결정실의 보유종목 | 보유 점검 | 내 주식의 같은 종목 |
| 결정실의 매수대상 | 가상 신규매수 카드가 있을 때만 가격 확인 | 신규매수의 같은 종목 |
| 결정실의 보류·제외 | 타이밍 대상 아님 표시 | 잘못된 진입 연결 없음 |
| 보유관리·신규매수 | 해당 종목의 직접 연결 기사 | 뉴스룸의 해당 기사 |
| 각 종목 | 분석·당시 기록 열기 | 새 홈의 해당 종목 상세 |

가상 예시의 결정실 입력은 3종목이다. 선정 자료가 없는 DEMO-G는 관찰 목록에 남기되 결정실 목록에서는 뺐다. 신규매수 카드는 DEMO-E만 있으며 보류·미입력·보유종목을 섞지 않는다. 입력 자료가 없는 종목 주소를 열면 다른 종목으로 바꿔 보여주지 않고 안내한다. 이 예시의 분기는 운영 판정기를 새로 구현한 것이 아니다.

운영 결정실의 실제 연결은 판정·카드 유무·보유 여부를 확인한다. 가상 예시에 카드 부재를 나타내는 자료가 있는 것과, 운영 자료를 실제로 확인했다는 것은 구분한다.

## 복귀와 주소

- 내부 이동은 브라우저 뒤로·앞으로 이동과 공통 이전 화면을 지원한다. 종목·날짜·필터·메뉴 검색·읽던 위치를 보존한다.
- 종목 상세에서 출발 화면으로 돌아갈 때 뉴스 필터나 기록 날짜를 유지한다.
- 운영 화면은 새 탭으로 열어 미리보기 상태를 남긴다. 운영 화면 안에 새 메뉴를 설치한 것은 아니다.
- 사용자 입력 주소만 브라우저에 보존한다. `/ko/`를 입력하면 유지하고, 옛 경로를 입력하면 원래 경로를 사용한다.
- 공개 코드에는 운영 서버 주소·실제 보유 자료가 없다. DEMO 종목 코드를 운영 URL에 넘기지 않는다.
- 이전 주소 `manager`, `trading`, `space`, `themeLab`는 각각 펀드매니저실, 신규매수, 기존 사무실, 리서치센터로 이어진다.

## 검증

`node hokuto-classroom/tests/navigation-connections.test.cjs`를 사용한다. 13개 운영 경로의 중복·누락, 17개 전체 경로, 리서치/작전실 분리, 같은 종목의 화면 이동, 신규매수 대상 제한, 잘못된 직접 주소, 보유 경고의 기사 연결, 검색·날짜·필터·스크롤 복귀, 브라우저 뒤로·앞으로, 연결 주소와 이전 주소 호환을 확인한다.

이 검사는 브라우저 없는 상태 검사다. 지원되는 브라우저 검수 기능이 없어 실제 렌더링·휴대폰 화면 캡처 검수는 수행하지 못했다. 홈 CSS는 변경하지 않았다. 운영 서버 접속·렌더링은 미확인이다.
