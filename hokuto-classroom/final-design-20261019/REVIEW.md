# 호쿠토증권 v2.0 최종 통합 디자인 시안

2026-10-19 · 아스트라 작성 · 사용자 확인 및 Claude 웹 재검토 전 · 운영 미반영

## 이번 완성 범위

이미지 1의 픽셀 메뉴를 기준으로 알림 홈, 전체메뉴와 기존 19개 목적지의 공통 시각 체계를 통일했다. 알림 홈은 큰 역할별 아이콘, 진한 제목, 구역별 색과 테두리를 적용했다. 첫 구역은 중요 변화와 전체 뉴스 제목, 다음 구역은 종목 목록과 큰 차트다. 휴대폰에서는 한 열로 전환하고 하단 주요 메뉴를 유지한다.

뉴스는 기존 시안의 전체 6건이며 332건을 복제하지 않았다. 운영에 적용할 때 전체 뉴스 목록의 실제 건수와 제목을 연결해야 한다. 제목 → 기사 내용과 연결 근거 → 회사 분석 → 과거 기록 흐름을 유지한다.

전체메뉴의 19개 목적지는 같은 해시 경로를 유지하면서 이번 시안의 `home.html`로 통합했다. 원래 운영 연결 안내만 있는 화면은 운영 데이터를 채운 완성 기능으로 주장하지 않는다.

## 시각 규칙

- 뉴스·시장: 파랑. 보유 목록: 민트. 후보·실적: 보라. 판정·가격 조건: 금색. 결과·기록: 살구색.
- 구역색은 위치 안내다. 상승·하락, 매수·보류 판정을 뜻하지 않는다. 주가 등락은 기존 한국식 빨강/파랑을 유지한다.
- 픽셀은 장식과 아이콘에 사용한다. 한글 본문과 숫자는 읽기 쉬운 일반 서체다.
- PC: 큰 제목 38px, 주요 카드 제목 20~26px, 뉴스 제목 16px. 모바일: 페이지 제목 27~29px, 뉴스 15px, 주요 터치 영역 약 44px 이상.

## 차트 구현

TradingView Lightweight Charts 5.0.9를 공식 npm 패키지에서 받아 시안에 포함했다. 외부 CDN 로딩 없이 동작한다. Apache 2.0 LICENSE와 NOTICE를 `vendor/`에 포함하고 차트의 출처 로고와 저작권 표기를 유지했다.

캔들/종가선, 5일/20일 표시, MA5/MA10, 별도 거래량 영역, 가격축·날짜축, 교차선, 이동·확대, 크게 보기, 날짜별 수치와 표를 제공한다. 알림 홈·종목 상세·내 주식·신규매수의 차트에서 같은 표시 모듈을 재사용한다. 모바일 세로 스크롤을 위해 차트의 수직 터치 드래그를 끈다.

**기존 데이터에는 종가만 있다.** 모든 종가는 기존 시안과 동일하다. 시가·고가·저가·거래량·일자는 디자인 확인용 가상 값이며 차트 옆에 명시했다. 가격이 없는 유키 메디컬은 계속 자료 없음으로 표시한다. 가상 OHLCV를 운영 데이터로 연결하거나 종가로 실측 OHLCV를 추정해서는 안 된다. 운영 OHLCV가 없으면 종가선만 표시하고 캔들·거래량을 제공하지 않는다. 운영 분봉, 주봉, 월봉, 실시간 시세는 이번 시안에 없다.

## 수정 파일과 경계

`app.js`는 기존 `stock-home.js`를 복사하고 차트 렌더링 호출·통합 메뉴 이동·구역 색상 속성만 추가했다. 종목 원본, 뉴스 원본, 판정 계산, 후보 선정, 평가 계산은 변경하지 않았다. 기존 `stock-rooms.js`와 `stock-links.js`는 수정 없이 공유한다.

- `home.html`, `home-pixel.css`, `final.css`, `final-ui.js`: 홈 및 기존 상세 화면의 표현.
- `menu.html`, `menu.css`, `menu-final.css`, `menu.js`, `icons.svg`: 전체메뉴.
- `broker-charts.js`, `chart-fixture.js`, `vendor/`: 차트와 가상 데이터.
- `index.html`, `preview.css`, `preview.js`: PC/휴대폰 검토 화면.
- `numeric-verification.json`: 기존 데이터와 수치 비교 증거.

## 헤르메스/시그마 구현 지침

필수: 승인된 화면과 CSS를 운영의 기존 데이터·이벤트에 연결한다. 뉴스 전체 건수와 목록을 유지하고, 기존 직접/관계/미확인 구분을 보존한다. 종목·기사 식별자, 판정, 후보, 점수, 가격 기준 시각을 임의로 바꾸지 않는다. 차트는 운영 공급원이 실제 제공한 OHLCV만 사용하고 데이터 기준·지연 여부를 표시한다. 분할 조정 여부와 가격 단위를 맞춘다. 자료가 없으면 결측으로 유지한다.

선택: 운영 OHLCV 연결 뒤에 장기 기간·추가 지표를 검토한다. 현재 보유 데이터가 없는 분봉·주문 기능은 디자인 완성에 필요하지 않다.

## 승인 및 운영 반영 조건

1. 사용자 디자인 확인 → 아스트라 최종 지침 → Claude 웹 검토 → 반영된 지침으로 헤르메스/시그마 구현 → 결과를 아스트라에게 보고한다.
2. 점수·판정·후보 선정·데이터 연결에 닿거나 새 문구·상태를 추가하는 변경은 크기와 관계없이 Claude 웹 재검토 대상이다. 이번 차트와 안내 문구도 포함한다.
3. **같은 입력으로 점수·판정·숫자가 그대로임을 증명하는 검사 결과가 없으면 운영에 반영하지 않는다.** 이번 가상 시안 검사는 운영 입력과 11/10 수익 평가 검사를 대신하지 않는다.
4. 번역·추가 후보 로봇 완료 확인 전에는 운영 디자인 반영을 보류한다.
5. 반영 가능 시간: 운영 배치가 끝난 비거래 시간 중 헤르메스가 배치/평가와 충돌하지 않는 구간을 확인해 기록한다. 현재 운영 일정 미확인 상태이므로 임의의 시각을 확정하지 않는다.
6. 컷라인: 실행 직전 기존/신규 commit, 자료 스냅샷 시각, 실제 반영 시각(KST/JST), 적용 대상, 비교 결과를 기록한다. 11/10 평가 입력이나 과거 선정·수익 기록을 다시 쓰지 않는다.
7. 되돌리기: 배포 전 기존 HTML/CSS/JS 및 차트 의존성 묶음을 보존한다. 수치 차이·뉴스 누락·주요 연결 실패가 있으면 표현 파일을 이전 버전으로 되돌리고 동일 입력으로 재확인한다. 데이터와 평가 기록을 함께 되돌리거나 삭제하지 않는다.

## 검사 기록

- 7개 종목의 원본 객체 전체(가격·등락·판정·기록·종가 배열·평가) 동일성 검사 통과.
- 테마/시장 초과수익 계산 일치, 모든 캔들의 종가가 기존 배열과 동일, OHLC 범위 검사 통과.
- 결측 가격을 0 또는 가짜 차트로 채우지 않음.
- 19개 메뉴의 해시 목적지를 보존하고 통합 화면으로 연결.
- 브라우저 표시와 상호작용 검사는 배포 후 기록한다.
