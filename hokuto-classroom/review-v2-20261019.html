기존 v9.1의 청록 디자인과 6단계를 유지하면서 전체 뉴스 제목의 입구, 글자 크기와 대비, 다음 화면으로 가는 길을 정리했습니다.

새 첫 화면오늘 뉴스전체 메뉴·6단계

할 일과 처리 결과

  1. 운영 v1.0 대조 완료. 실제 첫 화면과 뉴스룸, 생성 소스를 확인했습니다. 홈의 전체 제목은 중요 사건 요약과 별도이며, 종목에 연결되지 않은 기사도 포함합니다.
  2. 전체 뉴스 진입 복원. 홈에 최신 제목과 나머지 펼치기, 전체 뉴스 보기, 개별 기사 진입을 추가했습니다. 휴대폰 하단에 뉴스가 있습니다.
  3. 가독성 개선. 기본 14px → 16px, 본문 15~16px 이상, 보조 글씨 13px 수준. 청록은 유지하고 설명·상태 문구를 짙게 했습니다.
  4. 처음 방문한 사람의 길 정리. 중요 변화 → 전체 뉴스 → 종목별 근거. 새 후보는 전체 메뉴에서 기존 6단계로 검토합니다.
  5. 중복 축소. 홈의 별도 성과 요약은 성적표로 모았습니다. 성적표·성과기록·선정성적은 전체 메뉴에 유지합니다.
  6. 연결 이름 정리. 별도 trading_logic.html 입구는 ‘매매 전략·규칙’으로 표시합니다. 신규매수실과 구분합니다.

전체 뉴스에서 지켜야 할 계약

항목확인된 운영 구조와 적용 원칙
제목·개수이미 생성된 뉴스룸의 전체 목록을 재사용하고, 같은 목록에서 개수를 셉니다. 332·352를 고정하지 않습니다.
기간·정렬운영 원본은 최근 24시간 목록. 홈은 뉴스 기준시각과 함께 최신순으로 보여줍니다. 당일 0시 이후 기사만으로 임의 변경하지 않습니다.
운영 표시기존 홈은 최신 20개 + 나머지 펼치기. 공개 시안은 기존 가상 기사 6개를 3개 + 나머지로 보여줍니다. 실제 뉴스 연동 완료를 뜻하지 않습니다.
연결기사의 고유 키로 해당 기사를 열고, 직접 연결 근거가 있는 회사만 연결합니다. 업종 참고·분석 대기는 임의 종목에 붙이지 않습니다.
원문·필터운영의 국가·속보·출처 필터, 한국어/일본어 원문 제목 전환, AI 번역 표지, 본문과 원문 링크를 보존해야 합니다. 시안은 자료가 있는 국가·연결범위·검색을 시연합니다.
분석 처리기사 수집·잡음 제외·점수·병합·판정은 다시 계산하지 않습니다. 운영 적용은 별도 확정 지침과 브랜치 검토 뒤 진행합니다.

운영 확인 근거: screen/build_today_ko.py, screen/build_news.py, screen/build_news_board_ko.py, screen/title_toggle.py. 공개 자료에는 개인 운영 주소·보유 내역을 포함하지 않았습니다.

핵심 연결 확인

  1. 홈 ‘오늘 뉴스 제목’ → 기사 내용·연결 근거 → 직접 연결 회사 → 현재 분석/변화·기록 → 뉴스 검색·필터·읽던 위치 복원.
  2. 리서치회의실 → 작전실 → 펀드매니저 전략실 → 종목검증실 → 결정실 → 신규매수실.
  3. 보류 회사는 신규매수실로 보내지 않고, 이미 가진 회사는 내 주식으로 연결.
  4. 보유 점검과 결정실 판정을 별도 칩으로 표시. 자료 부족·미입력을 정상이나 제외로 바꾸지 않음.
